SPACESCAPE V2

SpaceScape is the preliminary design for a 3d space exploration game I've been working on.

This version is extremely preliminary, with a lot of potential for endless more animations, planets, different ship types, objectives, missions, story progress and even different star systems. 

This was made entirely by me, I did not vibe code this, I used the Godot engine alongside the help of endless online tutorials to guide me. 

MAJOR FEATURES AND HOW THEY WERE PRODUCED:

SHIP MOVEMENT : The code was written completely by me, took around 3 days to complete and decide what I wanted for the finished movement mechanics to be. Despite the help of Godots presets, 3d movement required me to face the issues of 
- designing what inputs to take to enable 3d movement on all 3 axis' whilst keeping controls simple and intuitive 
- adjusting linear velocity according to rotation of the ship which is based on 4d quarternions that I had to learn of from scratch.
- preventing gymbal lock error for rotation
- designing a warp system that stops the ship when it reaches the vicinity of the target planet. 

3D MODELS: Meshes and materials in some part were made in godot itself, others were imported from blender, also made completely by me.

SPACE BACKGROUND : I had to learn to use spacescape.exe - a program that draws night sky/space textures for the custom background. Again, completely original to me.
